Backup manual

Crie uma cópia imediata do banco e baixe um arquivo JSON para guardar fora do computador.

O backup automático é executado diariamente enquanto o servidor estiver ligado. São mantidos os últimos 30 dias no computador. Para maior segurança, baixe cópias externas periodicamente.

Restaurar backup

Selecione um arquivo JSON de backup gerado por este CRM. Antes de restaurar, o sistema cria uma cópia de segurança do banco atual.
